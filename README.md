# OPT Tracker

Интерактивный трекер 90-дневного плана. Визуальная система вдохновлена [Trivero](https://trivero.ru/): графитовые поверхности, красный акцент, прямые углы, тонкие границы, Oswald для заголовков, Inter для текста и Roboto Mono для служебных подписей. Контент, изображения и логика сайта Trivero не используются.

## MVP

- Обзор 13 недель с общей статистикой и прогрессом.
- Быстрый недельный экран: цель, время и семь задач.
- Отдельные вкладки для метрик YouTube, Telegram, других проектов и недельного разбора.
- Автосохранение в IndexedDB на текущем устройстве.
- Экспорт и импорт резервной копии JSON; экспорт сводки CSV.
- Адаптивный интерфейс для телефона и компьютера.

Данные не отправляются на сервер. В MVP нет аккаунтов и синхронизации между устройствами: для переноса используется JSON-копия. Пустые поля в статистике не приравниваются к нулю.

## Стек

- Next.js 16.4 App Router, React 19.3, TypeScript 5.9.
- Tailwind CSS 4.3 и собственные дизайн-токены в CSS.
- IndexedDB через маленькую библиотеку `idb-keyval`.
- Zod 4 для проверки импортируемой копии.
- Biome 2.5 для форматирования и статической проверки.
- Локальные шрифты `@fontsource` без сетевого запроса при открытии приложения.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).

```bash
npm run lint
npm run typecheck
npm run build
```

Для проекта нужен Node.js 20.9+; рекомендован актуальный LTS. В файле `lib/tracker.ts` находятся даты, названия задач и модель данных. Браузерная база использует ключ `opt-tracker-v1`.
