# OPT Tracker

Интерактивный трекер 90-дневного плана. Визуальная система вдохновлена [Trivero](https://trivero.ru/): графитовые поверхности, красный акцент, прямые углы, тонкие границы, Oswald для заголовков, Inter для текста и Roboto Mono для служебных подписей. Контент, изображения и логика сайта Trivero не используются.

## MVP

- Обзор 13 недель с общей статистикой и прогрессом.
- Быстрый недельный экран: цель, время и семь задач.
- Отдельные вкладки для метрик YouTube, Telegram, других проектов и недельного разбора.
- Автосохранение в IndexedDB на текущем устройстве.
- Экспорт и импорт резервной копии JSON; экспорт сводки CSV.
- Адаптивный интерфейс для телефона и компьютера.
- Отдельный раздел заметок: быстрый редактор, поиск, закрепление, удаление и экспорт JSON.
- Заметки можно вести локально. После подключения Supabase доступен вход по email и паролю и синхронизация между устройствами.

Данные **трекера** остаются в браузере конкретного устройства. Заметки без входа тоже остаются локальными. После входа заметки отправляются в личную базу Supabase и доступны на других устройствах. Локальные заметки переносятся в аккаунт при первом входе. Пустые поля статистики не приравниваются к нулю.

## Стек

- Next.js 16.4 App Router, React 19.3, TypeScript 5.9.
- Tailwind CSS 4.3 и собственные дизайн-токены в CSS.
- IndexedDB через маленькую библиотеку `idb-keyval`.
- Supabase Auth и Postgres с Row Level Security для личных заметок.
- Zod 4 для проверки импортируемой копии.
- Biome 2.5 для форматирования и статической проверки.
- Локальные шрифты `@fontsource` без сетевого запроса при открытии приложения.

## Публикация на Vercel

Сайт: [opt-xi-seven.vercel.app](https://opt-xi-seven.vercel.app/). Проект собран как статический экспорт Next.js и размещён на бесплатном плане Hobby.

Пока Vercel не подключён к GitHub, обновления публикуются вручную из папки проекта через `vercel deploy --prod`. Для автоматической публикации после push нужно подключить репозиторий к проекту `opt` в настройках Vercel → **Git**.

Данные трекера остаются в IndexedDB конкретного браузера и не синхронизируются между устройствами. Перед переходом с локальной версии на опубликованную экспортируйте JSON-копию и импортируйте её на новом адресе: браузер разделяет хранилища разных сайтов.

### Подключение входа и синхронизации заметок

1. Создайте бесплатный проект на [Supabase](https://supabase.com/dashboard/projects). Достаточно плана Free.
2. Откройте **SQL Editor** проекта и выполните [supabase/notes.sql](supabase/notes.sql). Скрипт создаёт таблицу и ограничивает чтение/запись заметок владельцем через RLS.
3. В проекте Supabase откройте **Connect** и скопируйте Project URL и **publishable key**. Не используйте secret/service role key в браузере.
4. В Vercel → проект `opt` → **Settings → Environment Variables** добавьте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` для Production. Значения для локального запуска можно положить в `.env.local` по образцу [.env.example](.env.example).
5. В Supabase → **Authentication → URL Configuration** задайте Site URL `https://opt-xi-seven.vercel.app`. Включите вход по email и подтверждение адреса. Для стандартной почтовой службы Supabase действуют ограничения: она подходит для владельца проекта и тестирования, а для широкого круга пользователей понадобится свой SMTP.
6. Пересоберите и опубликуйте сайт на Vercel: `vercel deploy --prod`. Переменные `NEXT_PUBLIC_*` встраиваются в статический JavaScript во время сборки.

После публикации нажмите **Мои заметки → Войти для синхронизации → Создать аккаунт**. Подтвердите email, затем войдите с теми же данными на телефоне. Для безопасности регистрация должна оставаться с подтверждением email. Заметки синхронизируются при сохранении и при возвращении на вкладку; при отсутствии сети они сохраняются локально и отправляются после восстановления связи. При одновременном редактировании одной заметки на разных устройствах сохраняется последняя версия целиком.

Для проекта нужен Node.js 20.9+; рекомендован актуальный LTS. В файле `lib/tracker.ts` находятся даты, названия задач и модель данных. Браузерная база использует ключ `opt-tracker-v1`.
